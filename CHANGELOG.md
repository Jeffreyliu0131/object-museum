## [0.1.0] - 2026-08-30

### Added

- Browser-local single-object exhibit workflow with exact-source provenance,
  narrator review, local persistence, conflict detection, and verified clear.
- Three AI-generated synthetic JPEG fixtures and synthetic stories/metadata,
  offered under CC0-1.0 to the extent rights exist.
- Public architecture, privacy, limitation, implementation, verification, and
  experience-acceptance documentation.
- Public contribution, conduct, security, and support policies.
- Structured bug and feature request forms with an explicit synthetic-data-only
  boundary.
- Pull request checklist covering evidence, provenance, privacy, and
  verification.
- Node.js 22 CI for linting, type checking, tests, and production builds.
- Weekly Dependabot checks for npm and GitHub Actions dependencies.

### Changed

- Licensed code and ordinary documentation under MIT, © 2026 Kairui Liu.
- Prepared the source-only public repository metadata for
  `Jeffreyliu0131/object-museum`.

### Removed

- The bundled system-voice narration fixture and every code, manifest,
  documentation, test, build, and public-screenshot reference to it. Optional
  user-selected local audio remains playback-only.
